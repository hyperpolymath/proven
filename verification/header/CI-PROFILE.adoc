= Header and reusable workflow validation profiles

The ABI definitions remain Idris2 and the FFI/API implementation remains pure
Zig. Atoma's scalar replay pins `21346ae1c85b7773a4bc16df51cb1ec5977f6b65`;
this workflow migration changes none of those source or contract bytes.
Compiler refinement and the complete foreign boundary remain unproved.

== Canonical governance migration

Four callers pin Standards default-branch revision
`84c2d1c1b040c9d7b8924532fa77e71e63d72c66`. Its canonical policy recognizes
the moved `metadatastician/standards` owner, its baseline validator uses file
inputs rather than overflowing the argument vector, and its workflow helpers
are bound to the reusable's own revision.

This replaces the isolated `6da35965d761761c09e3779e5639012de767bb48`
lock-metadata backport. That backport repaired startup, but the default-branch
ancestry policy correctly rejected it. The removed caller-side lock
experiment is not restored.

The four exact reusable paths and their two nested DEED/K9 conformance paths
must be admitted in the repository Actions allowlist. The nested paths pin
`bfa851f5291edd82d01dfb33cb8d81b3002d2f89`; no owner-wide wildcard is needed.
DEED/K9 retain the canonical advisory default; existing gates are not disabled.
Hypatia explicitly scans the whole tree, preserving the previous scope.
Its validated baseline and threshold behavior remain the canonical defaults.

The secret scanner declares no inherited secrets. Its caller forwards none
and no longer requests pull-request write permission. This addresses
SonarCloud rule `githubactions:S7635` without an exemption.

== Evidence and limits

Header RefC soundness, header theory replay and Atoma scalar replay are separate
from generic governance checks. Passing one is not evidence that the others
passed. The final PR head must pass hosted CI and review before merge; the
migration's hosted result is pending when this document is introduced.
