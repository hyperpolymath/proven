== Proof-companion inclusion in the package gate

The complete repository tree at +8f131687+ contains 93 +src/Proven/**/Proofs.idr+ companion files. +proven.ipkg+ declares 29 of them (307 package module paths overall). The dedicated +proof-check+ job explicitly checks just the proof companions named in that package; its own comment describes the other 64 as deliberately excluded because of build- or environment-blocked and work-in-progress status. This is an *intentional support boundary*, not evidence that its green job missed a module it promised to check.

The 51 claimed-discharge annotations in the current census split into:

* *24 annotations* across 7 source files whose companion proof modules are listed in +proven.ipkg+.
* *27 annotations* across 9 source files whose companion proof modules are **not** in +proven.ipkg+.

These figures identify a verification-coverage question, not 27 false claims. There may be separate checks; the next pass must locate their exact run receipts or mark them not independently checked. In particular, do *not* add the 64 excluded modules wholesale to the package to manufacture CI coverage; first address their build prerequisites and define the supported release envelope.
